# 验证记录

日期：2026-10-22。运行版本：Node.js 24.13.0、Cesium 1.146.0、本机 Chrome 的无界面 WebGL/SwiftShader 渲染。

本记录验证的是本仓库内的模拟 ArcGIS 缓存，原点为 `(-400,400)`，256×256，零级分辨率 `0.703125°/像素`，随后逐级减半。没有接入用户的真实 ArcGIS 服务。

## 已通过

- 18 项 Node 测试：原始切片索引、父子关系、弧度/度转换、单源图片直接请求、调度限流透传、认证参数继承、LOD 标签映射与元数据约束。
- 真实 Cesium `ImageryLayer` 测试：每个全球地形根瓦片与四张源图关联，相邻地形块复用源影像，极区/日期变更线保留完整图片 UV，影像 LOD 与标准网格一致。
- TypeScript 严格检查：可直接传入 Cesium 的影像层 API，无需类型断言。
- Vite 生产构建及生产预览中的 3D/2D 浏览器检查。
- 浏览器无未捕获运行错误；模拟服务元数据及源切片通过 HTTP 实际加载。
- npm 依赖审计：0 个已报告漏洞。

浏览器以地理位置定位，然后从截图中读取对应像素，与服务生成的经纬度编码色比较：

| 经度 | 纬度 | 期望 RGB | 实测 RGB |
| --- | --- | --- | --- |
| 0 | 0 | 125,125,145 | 125,125,145 |
| 110 | 35 | 180,160,145 | 180,160,145 |
| 179 | 15 | 215,140,145 | 215,140,145 |
| -179 | -20 | 36,105,145 | 36,105,145 |
| 25 | 84 | 138,209,145 | 138,209,145 |
| 20 | -84 | 135,41,145 | 135,41,145 |

这验证了原点改变后的定位与纹理映射，不构成真实服务器的缓存完整性、CORS、认证或性能验收。

## 复现

```sh
npm ci
# 无可用浏览器时：npx playwright install chromium
npm run check
```

检查程序生成 `artifacts/browser-report.json`、`artifacts/demo-3d.png` 与 `artifacts/demo-2d.png`。`artifacts/` 是本地生成目录，不提交 Git。
